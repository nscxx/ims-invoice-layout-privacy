IMS 发票排版打印 Chrome 扩展程序

Privacy Policy

隐私政策

生效及最后更新日期：2026 年 8 月 17 日

核心原则：发票读取、PDF 排版和文件生成全部在用户的浏览器本地完成。扩展不会把发票、页面内容或个人信息上传给开发者或第三方。

处理的数据

为完成用户主动发起的发票排版操作，本扩展会在本地处理：

  • IMS OA 费用报销页面中电子发票附件的文件名、附件地址和 PDF 内容；
  • 自动读取失败后，由用户主动选择的本地 PDF 文件；
  • 由上述文件在本地生成的 A4 双联排版 PDF。

发票中可能包含姓名、企业名称、税号、交易金额等个人身份或财务信息。本扩展不会分析这些信息，也不会将其用于发票排版以外的目的。

使用目的

上述数据只用于识别电子发票、将发票自动排成每张 A4 纸上下两联，并向用户提供预览、下载和打印功能。

本扩展不进行广告投放、用户画像、行为分析、营销、信用评估或与其单一用途无关的处理。

传输与共享

  • 不会把发票、页面内容或生成结果传输给开发者或任何第三方；
  • 不会出售、出租或共享用户数据；
  • 不会使用第三方分析、广告或追踪服务；
  • 不会允许开发者、员工或其他人员读取用户的发票内容。

扩展仅会通过用户当前已登录的 IMS OA 会话，以 HTTPS 从 imsdnr.inmyshow.com 读取用户主动要求处理的发票附件。

存储与删除

扩展不建立用户账户，不在开发者服务器存储数据，也不使用浏览器同步存储保存发票。

处理中的数据仅存在于当前浏览器会话内存。页面关闭或刷新后，临时结果会被释放；用户主动下载的文件由用户自行管理和删除。

网站权限

扩展仅在 IMS OA 费用报销页面运行，并只请求 https://imsdnr.inmyshow.com/* 的访问权限。该权限用于识别发票附件、读取 PDF，以及在页面中显示排版和打印入口。

扩展不会访问其他网站，不会读取浏览历史、密码、身份验证 Cookie、邮件或个人通信。

远程代码

扩展的全部 JavaScript 和 PDF 处理依赖均包含在发布的软件包中，不会从外部服务器加载或执行 JavaScript、WebAssembly 或其他远程代码。

政策更新

如果扩展功能或数据处理方式发生变化，本页面会同步更新生效日期和相关说明。任何新增的数据处理都将遵守 Chrome Web Store 用户数据政策。

联系我们

如对本隐私政策或扩展的数据处理方式有疑问，请通过 GitHub 仓库的 Issues 页面联系我们。
